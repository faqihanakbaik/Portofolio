Saya adalah siswa kelas XII RPL di SMKN 20 Jakarta yang berfokus pada pengembangan web dan eksplorasi UI/UX. Saya belajar membangun aplikasi menggunakan HTML, CSS, JavaScript, PHP, Laravel, serta teknologi database; di luar web, saya juga mengeksplorasi pengembangan aplikasi mobile.
